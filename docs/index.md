# Horrorometer for Kodi

1. Download [Horrorometer for Kodi v0.1.2](plugin.video.horrorometer-0.1.2.zip).
2. In Kodi, go to **Settings → System → Add-ons** and enable **Unknown sources** for ZIP installation.
3. Go to **Add-ons → Install from zip file** and select the ZIP.
4. Open the add-on and select **Authorize Horrorometer**. Scan the QR code with your phone camera and approve access after signing in. You can also visit the URL shown in Kodi and enter the displayed code.
